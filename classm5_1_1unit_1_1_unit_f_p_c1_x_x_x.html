Detailed Description

Base class for FPC1xxx family.

Note
Family spec
Chip Resolution Unit
FPC1020 192x192
FPC1020AM 192x192
FPC1020AP 192x192
FPC1020A 160x160 Unit Finger (SKU:U008)
FPC1021 160x160
FPC1024 192x192
FPC1025 160x160
FPC1523 96x96
